# 魔法秘艺 Ars Magica 中文翻译资源

**Ars Magica — Simplified Chinese Translation Project**

> 译者及维护者：椅子 / yeaz
>
> 联系方式：QQ 2455821829 / Email: [erya.wygzzgeds@gmail.com](mailto:erya.wygzzgeds@gmail.com) / Discord: _yeaz_

本项目旨在将《魔法秘艺》（*Ars Magica*）规则及相关资料翻译为简体中文，降低中文玩家接触这一游戏系统的语言门槛。项目以 Atlas Games 开放授权的第五版规则文本为核心，同时收录部分补充规则、游戏辅助资料及第三方创作。所有内容均以 Markdown 或其他便于阅读和使用的格式整理，持续更新。

翻译过程中使用了生成式 AI 辅助，并经过人工完整核对。这是我第一次承担如此规模的翻译项目，难免存在问题，欢迎提出修改建议或参与校对。

可以通过 GitHub Issues、Pull Requests 或上述联系方式和我交流。如果你希望帮助推广本项目，或者有意合作，也欢迎联系！
